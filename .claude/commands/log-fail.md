Зафиксировать факап. По описанию инцидента:

1. Добавь запись СВЕРХУ (сразу после шапки) в `docs/failures.md`:
   дата, что сломалось, ложный след (если был), как починили, как не повторить.
   В `CLAUDE.md` НЕ писать — он грузится в каждый запрос и должен остаться коротким.
2. Если из факапа следует постоянное правило диагностики — строка в таблицу
   «симптом → первая команда» в `CLAUDE.md`, подробности в `docs/troubleshooting.md`.
3. Гипотезу помечай гипотезой, а не фактом.
4. Закоммить:

```
git add docs/failures.md docs/troubleshooting.md CLAUDE.md
git commit -m "log: <короткое описание факапа>"
git push
```
